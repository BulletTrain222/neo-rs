## Summary

The main story is a chain of progress flags (SPEC-0049) that level scripts (SPEC-0030 and the level-script specs SPEC-0032, SPEC-0037, SPEC-0039, SPEC-0041 to SPEC-0045) set and test across four acts. The game's own quest table names every step: its first 158 rows are the main story and its last 80 rows are side quests. A step is listed in the journal while its start flag is on and its done flag is off (SPEC-0049, Quest steps and the journal). The player controls Tor alone in Act 1, Roberta alone in Act 2, and both heroes with free switching from the start of Act 3 (SPEC-0053). Each act begins with an act-start call. The story ends in the Darkest Faerie fight (SPEC-0054), either with the finale movie, which leads through the epilogue in pack 1300 to the credits, or with the timeout ending. With this spec the clean side can lay out the story order, check that every story step has a flag setter, a route into its area and a way out, and build an automated story test that walks the steps in order.

## Where it lives on the disc

- Quest rows: archive resource 533, data table 1 (238 rows of 36 bytes; SPEC-0024 table 1 and SPEC-0049 Quest rows). Rows 0 to 157 are the main story, rows 158 to 237 side quests. High.
- Area names: archive resource 533, data table 5 (77 rows of 8 bytes; SPEC-0024 table 5). The quest row's scene id indexes this table. High.
- Stage table (the start-point checkpoints): archive resource 533, table 11 (SPEC-0049, Stage table rows).
- Act starts, flag writes and tests, movies, boss-fight instances, item gifts and area changes: the level scripts of the world packs named below (SPEC-0030 calls TriggerActStart, SetGameState, QueryGameState, PlayFMV, BossFightTweakHero, GiveItemToHero, SetHeroSwapMode, SwitchHero, SetGameOver and the transition calls). Packs are archive resource numbers (SPEC-0006).
- Area-pair table: boot program data at virtual address 0x31EEE0, 25 entries of two 32-bit values (SPEC-0006, area-pair test). The values are world-pack archive resource numbers: 23 pairs, then two zero entries. Read it at run time; it is not copied here. Medium-High for the values being pack numbers.
